# 🚀 World-Class Developer Portfolio & System Dashboard

A modern, highly responsive, glassmorphism-inspired personal portfolio web application built using **Python (Flask)**, **HTML5/CSS3**, and **JavaScript**. Continuously deployed on **Render** with direct email communication pathways.

---

## 🌟 Live Demo
👉 **[View Portfolio Online](https://my-cool-app-4qhr.onrender.com)**

---

## ✨ Features & Architecture

* **🎨 Cyberpunk Glassmorphic UI:** Modern UI design featuring ambient dynamic glowing orbs, interactive 3D card tilts, and smooth transitions.
* **⌨️ Dynamic Typewriter Effect:** Auto-typing text header highlighting core skills.
* **📊 GitHub Stats API:** Live real-time integration displaying dynamic engineering activity metrics.
* **📩 Zero-Backend Email Engine:** Direct contact portal routing incoming messages straight to personal Gmail without intermediary databases.
* **🔒 Production Hardened Backend:** Built with Flask, featuring CORS support, strict input length sanitization, error-logging, and environment-aware debug flags.

---

## 🛠️ Tech Stack & Dependencies

* **Backend Framework:** Python 3 / Flask
* **WSGI Production Server:** Gunicorn
* **Frontend Languages:** HTML5, Modern CSS3, JavaScript (ES6+)
* **Cross-Origin Handling:** Flask-CORS
* **Version Control & CI/CD:** Git, GitHub, Render PaaS
